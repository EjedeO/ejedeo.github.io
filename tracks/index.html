Running tracks

Where you can actually run laps

Real ovals only — no trails, no park loops. Every track says plainly whether the public can use it, because a locked gate at 6am is the whole problem.

  • Open to the public — confirmed usable
  • Restricted hours — usable, with limits
  • Access unconfirmed — call first
  • Not open — listed as a landmark

Access rules change and gates get locked. Where a track is marked unconfirmed, it means nobody has verified it — not that it is open.
